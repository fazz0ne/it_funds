# it_funds
https://github.com/Hexlet/ru-test-assignments/tree/main/analytics/vk-analitik-dannykh \
Тестовое задание VK (ML): исследовательский анализ рекламных событий. Цель — выяснить, какие устройства, аудитории и форматы рекламы дают наибольший отклик, и сформулировать гипотезу по оптимизации рекламных ресурсов. В ходе работы

## Структура репозитория
| Файл | Описание |
|---|---|
| `main.ipynb` | Ноутбук с анализом, графиками и выводами |
| `ads_events.csv` | Исходные данные (~171,7 тыс. строк) |
| `README.md` | Описание проекта |

## Методология
1. **Предобработка.** Пропуски в `Age` заполнены средним, в `Gender` — целой частью среднего.
2. **Метрики.**
   - *Доля откликов* = число откликов / число всех событий.
   - *CTR по формату* = число откликов / число показов данного формата, в %.
3. **Срезы.** Для каждого среза считаются общая доля откликов, количество откликов по форматам и CTR по форматам:
   - по типу устройства;
   - по полу;
   - по возрастным группам (границы по квартилям): 14–26, 26–33, 33–42, 42–70.
